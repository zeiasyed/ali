# Week uploads

Drop weekly assignments here so Cursor can build Math or Social Studies courses.

## How to use

1. In the Ali app, choose **Math** or **Social Studies**.
2. Tap **Upload Week’s Work**.
3. Pick a PDF, photo, or Word file whose name includes the week (e.g. `Week_9_student_edition.pdf`).
4. When asked, choose **this `week-uploads` folder** (once). The file is saved under `inbox/`.
5. Cursor opens with a build prompt — press **Send** / confirm.
6. The app shows a progress bar while `status.json` updates, then **Ready**.

## Files

- `inbox/` — uploaded source files (PDF / images / Word)
- `status.json` — build progress (`phase`, `progress`, `message`)
